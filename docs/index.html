API Документация: Покупка услуг

Общее описание

API предназначено для партнеров системы и позволяет покупать услуги (в текущей реализации — boost сервера). Все ответы возвращаются в формате JSON.

Аутентификация

Аутентификация осуществляется с помощью:

  • login — API-логин партнера
  • key — API-ключ партнера

Проверка выполняется по таблице ga_users:

  • Пользователь должен иметь роль partner
  • API-ключ должен совпадать с params.key_api

Endpoint: Покупка услуги

URL: /api

Метод: GET | POST

Обязательные параметры

ПараметрТипОписание
loginstringAPI-логин партнера
keystringAPI-ключ партнера
svstringСервер в формате IP:PORT
servicesintID услуги
gamestringИдентификатор игры

Логика работы

  1. Проверка наличия всех обязательных параметров
  2. Проверка партнера и API-ключа
  3. Проверка существования услуги
  4. Расчет цены с учетом скидки партнера (discount_api)
  5. Проверка баланса партнера
  6. Списание средств
  7. Создание или получение сервера
  8. Применение услуги (boost)
  9. Логирование платежа

Применение услуги: Boost

  • Если сервер уже имеет активный boost — значение увеличивается
  • Если boost отсутствует:
    • Проверяется лимит boost-серверов
    • При превышении лимита самый старый boost уменьшается/сбрасывается
    • Текущему серверу назначается boost и позиция

Успешный ответ

{
  "status": "success",
  "code": "purchased",
  "message": "Server successfully added"
}

Возможные ошибки

CodeОписание
no_paramsНе передан обязательный параметр
no_partnerПользователь не является партнером
no_valid_keyНеверный API-ключ
no_serviceУслуга не найдена
no_moneyНедостаточно средств
server_is_bannedСервер заблокирован

Пример ошибки

{
  "status": "error",
  "code": "no_money",
  "message": "Not enough money"
}

Примечания

  • Все операции покупки необратимы
  • API не использует подписи или токены — защита строится на login + key
  • Рекомендуется использовать HTTPS
